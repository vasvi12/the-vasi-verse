# Builds.fig

**Frame:** Desktop 1440px
**Style:** Editorial • Premium • Product Launch

---

## Vision

I want Builds to feel like Apple's Mac / iPhone / iPad lineup. Not like a portfolio. Not like Behance. Not like Dribbble. It should feel like you're browsing a company's product catalog.

## Overall Flow

Navigation → Hero → StudioAI → Growth Alpha → DotRyder → Footer. No sidebars. No filters. No unnecessary UI. Just products.

## Navigation

Exactly same as Home. Never redesign navigation. Consistency is key.

## Hero Section

Height 340px. Left aligned. Large whitespace.

Small Label: BUILDS — Geist Mono, 14px, Accent Blue.

Heading: "Products I've Built. Businesses I've Scaled. Problems I've Solved." — Geist, 64px, Bold, maximum 3 lines.

Supporting Text: "Every build represents a different stage of my journey—from founding a marketing company, validating an AI product, to consulting on product strategy." — Inter, 20px, Secondary Text, maximum width 720px.

Right Side Metadata (very minimal): PROJECTS 03 · ROLE Founder / Product Manager / Consultant · LAST UPDATED August 2026. Looks like documentation.

## Scroll

Huge breathing space. 140px.

## Product Card Layout

Forget normal cards. Think Apple. One product. One section. Each Build occupies approximately 100vh. Structure: Product Image → StudioAI → Summary → Metadata → Highlights → CTA. Very minimal.

## Hover Behaviour

Image → Brightness +5% → Scale 1.02 → Shadow slight → Arrow moves 6px. Nothing flashy.

## Scroll Behaviour

Every product enters slowly. Fade. Move upward 12px. Never slide, bounce, rotate, or parallax.

## Background

Entire page #080B12. No section colors. No alternating backgrounds. Consistency.

## Footer

"Every product begins with curiosity." — Geist, 48px → Connect CTA → Minimal Footer.

## Mobile

Products become stacked: Image → Heading → Metadata → Buttons. Nothing changes.

## Assets Needed

We will create three hero visuals.

- StudioAI: AI workspace, dark dashboard, floating asset pipeline, premium UI render.
- Growth Alpha: Growth analytics dashboard, marketing metrics, strategy board, performance graphs.
- DotRyder: Dark mobility interface, route visualization, city map, rider & driver ecosystem illustration.

Each should feel like a launch poster, not a screenshot.

## Motion

Card reveal 600ms. Image fade 450ms. CTA hover 250ms. Page transition 700ms.

## Success Criteria

A recruiter should spend at least 2–3 minutes on this page because the products feel substantial and thoughtfully presented.
