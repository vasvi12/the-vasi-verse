# Resume.fig

**Frame:** Desktop 1440px
**Style:** Clean • Documentation • Professional

---

## Context

Resume and Connect should actually be the simplest pages on the website. The mistake most portfolios make is over-designing them. By the time a recruiter reaches these pages, they've already decided whether they're interested. These pages should simply remove friction.

## Philosophy

The Resume page is not another portfolio page. It is a download center. The resume itself is the product.

## Layout

Navigation → Hero → Resume Preview → Quick Facts → Download CTA → Footer.

## Hero

Height 300px.

Small Label: RESUME — Geist Mono, Accent Blue.

Heading: "A concise overview of my journey." — Geist, 64px, Bold.

Supporting Text: "A one-page summary of my experience, product thinking, technical background, and leadership journey." — Inter, 20px, max width 620px.

Right Metadata: VERSION v2.3 · UPDATED August 2026 · FORMAT PDF · ROLE Product Manager. Documentation style.

## Resume Preview

Instead of embedding the full PDF immediately, use a large preview card:

```
┌──────────────────────────────────────┐
│                                      │
│          Resume Preview              │
│      (Thumbnail of first page)       │
│                                      │
│      [Open PDF]  [Download PDF]      │
│                                      │
└──────────────────────────────────────┘
```

Width 900px. Centered. Radius 24px. Surface background.

## Quick Facts

Below the preview, create a 2-column metadata grid:

- EDUCATION — BE Computer Science
- EXPERIENCE — Founder • Product
- LOCATION — Bangalore
- OPEN TO — PM / APM Roles
- SPECIALIZATION — B2B SaaS Growth / AI Products
- LANGUAGES — English / Kannada / Hindi

Presented exactly like internal product documentation.

## Primary CTA

Large filled button: Download Resume.

## Secondary CTA

View LinkedIn.

## Background

Keep exactly the same. No illustrations. No graphics. Minimal.

## Motion

Preview fades in. Buttons animate. Nothing else.

## Footer

"Every opportunity starts with a conversation."

## Success Criteria

Resume accessible within one click. Recruiter spends less than 10 seconds finding the download. Page reinforces professionalism.
