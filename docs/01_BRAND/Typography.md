# Typography System

**Product:** The Vasi Verse
**Version:** 1.0
**Owner:** Vasavi Hegde
**Status:** Locked

---

## Purpose

Typography is the primary visual identity of The Vasi Verse. Without relying on illustrations, photography, or decorative graphics, typography communicates hierarchy, confidence, rhythm, and personality. Every font size, weight, spacing, and alignment should reinforce the feeling of a premium software product. Users should remember the clarity of the interface before noticing the typography itself.

## Typography Philosophy

Typography is not decoration. Typography is navigation. Typography is hierarchy. Typography is branding. Typography is emotion. The website should communicate confidence through restraint. Large headlines create impact. Whitespace creates breathing room. Small metadata communicates precision. Nothing should ever feel loud.

## Font Stack

### Primary Display Typeface — Geist
Purpose: Large headlines, hero text, section titles, page titles, feature titles, major callouts. Geist feels modern, technical, minimal and premium while remaining highly readable. It reflects the personality of modern product companies.

### Primary Body Typeface — Inter
Purpose: Body copy, descriptions, navigation, buttons, metadata, labels, supporting text. Inter is clean, accessible and optimized for digital interfaces. It pairs naturally with Geist.

### Monospace Typeface — Geist Mono
Purpose: Metadata, version numbers, years, status, tags, project IDs, timeline, documentation labels. Example: Version v1.0, Status Validated, Updated August 2026.

## Typography Personality

Confident, Minimal, Calm, Modern, Precise, Editorial, Technical, Readable. Never Corporate, Decorative, Playful, or Over-styled.

## Hierarchy

Typography should naturally guide the eye. Every page follows the same reading order: Hero → Page Heading → Section Heading → Supporting Copy → Metadata → Captions. Users should never wonder where to read next.

## Font Weight System

- **700:** Display headlines, major titles.
- **600:** Section titles, cards, buttons.
- **500:** Navigation, labels, metadata.
- **400:** Body text, descriptions, supporting content.

Avoid using multiple weights unnecessarily. Consistency creates rhythm.

## Line Length

Maximum reading width 680px. Ideal characters per line 60–75. Never allow paragraphs to span the full screen. Readable content feels more premium.

## Alignment

Headlines, paragraphs, cards, and metadata are all left aligned. Never center long text. Centered text should only appear in the hero, footer CTA, and loading states. Everything else remains left aligned.

## Capitalization Rules

- Main Navigation: Title Case (Builds, Case Studies, Playground, Resume, Connect).
- Section Titles: Title Case.
- Metadata Labels: UPPERCASE (STATUS, ROLE, YEAR, VERSION).
- Buttons: Sentence Case (View Documentation, Explore Builds, Download Resume).

Avoid excessive uppercase. Reserve it for metadata only.

## Letter Spacing

- Display Headlines: Slightly Tight (-2%)
- Body: Normal
- Metadata: Expanded (+8%)

This creates a subtle documentation aesthetic.

## Numbers

All numerical values should use Geist Mono. Examples: 30+ Customer Interviews, 2026 Founder Product, v1.0 Status Validated. This creates visual consistency across the website.

## Typography Usage

- **Hero:** Large, minimal, powerful. One statement only. Never more than three lines.
- **Body Copy:** Short, scannable, meaningful. Avoid long paragraphs. Maximum 3–4 lines.
- **Card Titles:** One line whenever possible. Never wrap unnecessarily.
- **Metadata:** Small, monospace, uppercase, secondary color. Never compete with headings.

## Responsive Typography

- Desktop Display XL: 72px
- Tablet: 56px
- Mobile: 40px

Body scales proportionally. Maintain hierarchy. Never sacrifice readability.

## Accessibility

Maintain WCAG AA contrast. Never use font sizes below 14px. Avoid extremely thin font weights. Ensure line spacing remains generous. Readable typography is part of accessibility.

## Typography Rules

Never use more than three typefaces. Never justify text. Never use decorative fonts. Never use all caps for paragraphs. Never use excessive bold text. Never rely on color to establish hierarchy. Hierarchy should come primarily from typography.

## Emotional Goal

The typography should make users feel focused, calm, professional, curious, confident. It should never feel busy, loud, corporate, playful, or artificial.

## Final Principle

If all colors were removed from The Vasi Verse, the website should still feel premium through typography, spacing, and hierarchy alone. Typography is not one part of the design. Typography is the design.
