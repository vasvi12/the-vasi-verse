## Purpose

The Case Studies page demonstrates how Vasavi approaches product thinking independently. Unlike Builds, these are not products that were built commercially. They are structured product analyses created to showcase product intuition, strategic thinking, prioritization, experimentation, and communication.

This page exists to answer one question: "How does Vasavi think as a Product Manager?"

## User Goal

Recruiters should understand product thinking, decision making, strategic reasoning, communication, and structured problem solving without needing an interview.

## Hero

## Layout

## Card Layout

Large premium cards. Alternate left/right composition. Maximum width 1400px. Spacing 120px.

## Every Card Contains

Hero Visual → Title → Product → One-line Summary → Metadata → Key Focus Areas → View Case Study.

## Case Study Structure

- **Spotify:** Product critique, growth opportunities, retention strategy, metrics.
- **Blinkit:** Product expansion, operational optimization, user experience.
- **Uber:** Feature proposal, pricing, marketplace dynamics.
- **HootMe:** Activation, retention, community growth, network effects.

## Metadata

## CTA

## Images

Use realistic product-inspired visuals. No company logos as hero images. Instead use wireframes, journey maps, dashboard mockups, user flow diagrams, feature illustrations.

## Hover

Card elevation, border highlight, image zoom, arrow movement. 450ms.

## Acceptance Criteria

Recruiters immediately understand PM thinking. Case studies feel structured. Every card leads to premium documentation. Website remains lightweight.

## Final Principle

Case Studies demonstrate thinking. Builds demonstrate execution. Together they tell the complete PM story.
