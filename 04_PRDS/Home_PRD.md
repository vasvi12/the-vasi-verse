# Home Page PRD

**Product:** The Vasi Verse
**Page:** Home
**Version:** 1.0
**Status:** Locked

---

## Purpose

The homepage exists to accomplish three goals:

1. Immediately communicate who Vasavi Hegde is.
2. Establish a premium first impression.
3. Direct users toward documented proof of work.

The homepage should never feel like a traditional portfolio. It should feel like opening the landing page of a premium software product.

## Success Metrics

A recruiter should understand who Vasavi is within 10 seconds, understand the website structure within 20 seconds, click one of the three primary cards, and continue exploring. The homepage should create curiosity. Not answer every question.

## User

**Primary:** Product Recruiters, Hiring Managers, Startup Founders.
**Secondary:** Product Managers, Engineers, Designers.

## User Journey

Landing → Hero → Three Interactive Cards → Footer → Continue Exploring.

## Layout

Desktop: Navigation → Hero → Three Interactive Cards → Footer. The homepage should fit naturally into one scrolling experience. No unnecessary sections. No timeline. No testimonials. No skills. No experience. Those belong elsewhere.

## Navigation

Always visible. Minimal. VH · Builds · Case Studies · Playground · Resume · Connect.

Navigation background transparent initially. After scrolling: slight blur, dark surface, thin bottom border. Navigation height 72px.

## Hero

Height 100vh. The hero should occupy the entire first screen. No scrolling required to understand the identity.

### Hero Layout

Two-column layout. LEFT: Identity, Mission, CTA. RIGHT: Product Metadata. On mobile, single column; metadata moves below the introduction.

### Left Column

Large heading. Example: THE VASI VERSE. Spacing 48px → Founder • Product Manager • Engineer → Primary Statement: "Building products through customer discovery, technology, and execution." → Supporting Paragraph: "I build products, validate ideas, and document the thinking behind every decision. This website is a curated collection of products, case studies, and technical explorations." → Primary CTA: Explore My Work → Secondary CTA: Download Resume.

### Typography

- Website Name: Geist, 72px, Bold, Uppercase.
- Professional Identity: Inter, 16px, Medium, Uppercase, letter spacing 10%.
- Primary Statement: Geist, 56px, Bold, maximum 3 lines.
- Supporting Paragraph: Inter, 20px, maximum width 620px, line height 170%.

### Right Column

Title: PRODUCT OVERVIEW. Metadata displayed as premium product documentation:

- STATUS — Active Development
- VERSION — 1.0
- OWNER — Vasavi Hegde
- CATEGORY — Founder • Product Manager
- LOCATION — Bangalore, India
- MISSION — Build products that solve meaningful problems.

All labels: Geist Mono, Uppercase, 12px. Values: Inter, 16px.

### Hero Background

Primary Midnight Canvas. No illustrations. No avatar. No profile image. No decorative graphics. Only subtle gradients. Very minimal.

### Hero Animation

Page loads → Navigation fades → Website title fades → Professional identity fades → Primary statement fades → Supporting paragraph fades → Metadata fades → Buttons fade. Total duration 900ms. Never replay.

### Primary CTA

Label: Explore My Work. Scrolls smoothly to the Interactive Cards section.

### Secondary CTA

Download Resume. Opens Resume page.

## Interactive Cards Section

Purpose: Provide three clear exploration paths. Cards should feel like premium software products.

### Layout

Desktop: 3 equal-width cards, gap 32px. Tablet: 2 columns. Mobile: 1 column.

### Card One — BUILDS

Subtitle: Products I've built and the problems they solve. Metadata: 3 Projects. Status: Live. Destination: Builds Page. Hover: Image brightens, card lifts, border brightens, arrow animates.

### Card Two — CASE STUDIES

Subtitle: Independent product thinking and strategic analysis. Metadata: 4 Case Studies. Status: Growing. Destination: Case Studies.

### Card Three — PLAYGROUND

Subtitle: Experiments, engineering projects, and technical exploration. Metadata: Repositories. Status: Always Building. Destination: Playground.

### Card Design

Height 520px. Border Radius 24px. Padding 32px. Background Surface. Image occupies top 60%. Content occupies bottom. Every card follows identical layout.

### Card Images

Do NOT use stock photography. Use abstract product-inspired visuals. Examples: StudioAI (AI interface), Growth Alpha (analytics dashboard), Case Studies (wireframes), Playground (code editor), Figma (system diagrams). Minimal. Dark. Premium.

### Hover Behavior

Duration 450ms. Image scale 1.02. Brightness +5%. Card lift 4px. Border opacity increase. Arrow moves 4px. Cursor OPEN →. No dramatic effects.

### Page Transition

Click → Card slightly expands → Page fades → Destination loads. Transition 700ms.

## Footer

Large spacing. Statement: "Let's build something meaningful." → Connect Button → Email, LinkedIn, GitHub. Minimal. No unnecessary links.

## Responsive Behaviour

Desktop: Hero split layout. Tablet: Reduced typography; cards become two columns. Mobile: Single-column hero; single-column cards; buttons stack vertically; metadata appears beneath introduction.

## Accessibility

Keyboard navigation supported. Visible focus states. ARIA labels. Semantic HTML. Contrast ratio WCAG AA minimum.

## Performance

Hero loads instantly. Lazy load card images. 60 FPS animations. No layout shift. Images optimized.

## SEO

Title: The Vasi Verse | Vasavi Hegde. Description: Founder, Product Manager, and Engineer documenting products, case studies, and technical work.

## Acceptance Criteria

User understands identity immediately. Homepage loads in under 2 seconds. Three cards become the primary focus. Website feels premium. Users naturally continue exploring. Interface never distracts from the work.

## Final Principle

The homepage should not feel like introducing a person. It should feel like introducing a product. The product just happens to be built by — and represent — Vasavi Hegde.
